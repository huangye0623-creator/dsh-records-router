# 记录路由（先定位，再只读）

## 什么时候用

- 用户提到项目名（如 项目A、项目B）或某个功能/模块…
- 用户问"之前怎么做的 / 为什么 / 当时 / 进展 / 下一步 / 记录在哪"
- 需要翻交接记录、归档、旧报告，但**不想**把整个文件读进上下文

## 步骤

1. 在工作区根目录运行（原话传入）：

   ```powershell
   python tools\records\records_router.py query "<用户指令原话>"
   ```

   输出：识别到的方面、主题入口、必读基线、建议阅读的 3~6 段（文件:行号 + 分数）。

2. 只读命中的段（按输出里的编号）：

   ```powershell
   python tools\records\records_router.py read 1 2 3
   ```

   也可以用 `read` 工具直接读对应文件的 `起始行-结束行`。

3. 不够时再加：`--top=10`、换关键词、读主题入口里的项目 `03_产出`；仍不够再 `grep`。

4. 索引一般自动保鲜；手动重建：`... build`。

## 硬规则

- **禁止整读** `交接记录.md` 或 `交接归档\`——先 `query` 再 `read`。
- 任何问题都先看 `当前状态.md`（约 30 行），它是"现在在做什么"的唯一基线。
- 没有命中时：先读 `当前状态.md`，再 `grep` 关键词，不要凭记忆猜。
- 路由结果给的是"阅读计划"，不是结论；结论必须来自读到的原文。
